重构思路

  • 英雄卡承载唯一重心：连接状态可视化 + 主操作，替代原散落一排的按钮
  • 连接准备清单化：热点 / 蓝牙 / 声音权限三项，带状态徽标，一眼看出缺什么
  • 调试信息折叠：Shell 全局状态与日志默认收起，日常使用不干扰
  • 功能零删减：原有全部按钮 / 开关 / 输入框均保留，仅重组层级
  • M3 令牌制：色调变量直接映射 Android themes.xml，便于 1:1 还原

Android 映射

  • 卡片 → MaterialCardView（24dp 圆角）
  • 开关 → MaterialSwitch · 主按钮 → MaterialButton(pill)
  • 主题 → Theme.Material3.Dark + 自定义色调板
  • 弹窗 → MaterialAlertDialogBuilder · 轻提示 → Snackbar
